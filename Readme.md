## 📱 About

**Numora** is a simple and intuitive calculator application developed for Android using **Kotlin**. It provides fast and accurate mathematical calculations through a clean Material Design interface.

The app is designed with usability and performance in mind, making everyday calculations quick and effortless.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🗑️ Clear (AC)
- ⌫ Delete Last Digit
- 🔢 Decimal Calculations
- ⚡ Fast & Lightweight
- 🎨 Modern Material UI

---


## 🛠️ Tech Stack

- **Language:** Kotlin
- **IDE:** Android Studio
- **Minimum SDK:** 24+
- **UI:** XML
- **Architecture:** Activity-based

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/ShivamPrajapati-7/Numora.git
```

2. Open the project in Android Studio.

3. Sync Gradle.

4. Build and run the application on an emulator or Android device.

**OR**

1. Clone the repository

```bash
git clone https://github.com/ShivamPrajapati-7/Numora.git
```

2. There is APK file in Project Folder

3. Install it and Enjoy
